# v0.15 — Project-bound Harness / Archify team design preview

This read-only integration connects two previously reviewed, **non-authoritative**
Core candidates: the project-bound Harness team review plan and the pinned,
validated Archify architecture JSON + static Mermaid exporter.

## Operator-only API

`POST /integration-candidates/community/teams/{template}/project-architecture`

Use the same strict JSON request as the already merged Harness
`project-readiness` route: existing Project UUID, exact expected Harness blueprint
SHA-256, and bounded proposed planning ceilings. Four templates are supported:
`engineering_quality`, `business_research`, `youtube_content`, and
`trading_research`.

The endpoint first regenerates the current review plan from the trusted
Project, global Agent Registry, cross-project AgentInstance role reservations,
pinned Harness source and proposal. Stale fingerprints refuse with 409, missing
projects with 404, malformed or permission-widening proposals with 422. Pinned
Archify schema integrity or renderer export refusal returns a generic 503.
Operator authentication is mandatory.

The resulting digest-bound record includes the Project and blueprint identity,
Registry version, exact underlying review-plan digest, plan refusal reason,
read-only eligibility, four draft roles in VP → Director → Manager → Specialist
order, strict Archify JSON and a static Mermaid text preview. The diagram labels
use fixed role tiers and verified blueprint IDs, **not** user-supplied Project
names, arbitrary Agent instructions, private data, credentials or source paths.
The local pinned Archify JSON schema is validated before return; no HTML,
JavaScript, remote schema download or Archify renderer is executed.

## Authority boundary

A paused Project, insufficient draft budget, role collision or globally reserved
identity remains a **denied design**, not a partial or approved live team.
This preview never creates an AgentSpec, AgentInstance, OrganizationAssignment,
Task, Approval, Skill, Tool, Worker, Space grant or runtime budget. It cannot
trigger delegation, coding, browser access, WhatsApp, YouTube publication or
trading. The SHA-256 checksum proves byte integrity **only**, never operator
approval or authority; nobody may present a preview as a creation ticket.

Real specialist-team activation remains a separate later milestone requiring
durable Managing Director approval, exact Agent Registry revision, atomic role
reservation, Project/permission revalidation, enforced resource limits and
separate revocation/use-point qualification. UI PR #61 stays parked. REA remains
inactive. No change to the Media native-reader attempts is authorized.

## Qualification

`tests/test_community_archify_harness_project.py` exercises all four drafts,
deterministic strict-schema export, budget/project denial, operator authentication,
422/404/409 response behavior, no Task/audit/AgentInstance/assignment writes,
integrity tampering, source integrity refusal and absence of Project secret
names in diagram labels. Full CI and independent review are required before
merging this separate slice.
