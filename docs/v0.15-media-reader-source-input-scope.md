## Two-stage input decision, not yet cleared

### Stage D: descriptor only

A separate reviewed research allowance would make **one** GET to the exact
`.dsc` URL above, no redirects, proxy, alternate mirror, conditional retry or
ambient credentials. Reserve at most **65,536 response bytes**, one private
exclusive regular evidence file and a bounded journal before the request. A
non-200 response, short/oversized body, TLS uncertainty, close uncertainty,
write/fsync failure or timeout consumes the allowance and retains partial
failure evidence. No automatic second GET is permitted.

Before Stage D can run, an independent reviewer must pin the exact trusted
OpenPGP key identity/fingerprint, permitted source-signing purpose, key material
hash, validity/revocation policy and isolated verification tool/runtime identity.
The verifier must consume the exact retained `.dsc` bytes and an explicit
read-only keyring; no keyserver, user trustdb/cache, default key search,
attacker-supplied key or network during verification. A parsable descriptor
or a generic "good signature" message is insufficient. The authenticated
version/source name, native format, exactly one tarball filename/size/SHA and
all unexpected fields must be reviewed before a tarball input is selected.
The key and signature policy are **not yet pinned**, so Stage D remains
blocked and this document performs zero GETs.

### Stage T: archive, only after a separate exact review

Derive one literal HTTPS tarball URL solely from the authenticated descriptor
and independently reviewed Ubuntu source-pool mapping. Freeze its filename,
URL, exact **5,548,716-byte** length and the SHA256 above in a new immutable
input decision. If the signed descriptor differs, stop for design review;
never silently substitute its values for this candidate. Reserve the exact
archive bytes before one GET and retain its partial failure record on any
failure. No fallback, resume, range request, overwrite or retry. The two
response bodies together cannot exceed **5,614,252 bytes** under these
candidate caps; metadata/journals need a separate explicit bounded allowance.
The tarball URL remains **unresolved** until Stage D has passed. Stage T is
not authorized by Stage D or by this proposal.

## Isolated static inspection and acceptance

Treat the tarball and `.dsc` as data. Inspect with a separately reviewed,
bounded mature archive reader in a no-network, no-write sandbox; no package
scripts, build, extraction to host paths, executable import, `dpkg-deb`, shell
pipeline or acquired `.deb` read. Pin parser/tool source and license, maximum
entry count, per-member/aggregate expanded bytes, path/link/type rules,
streaming limits, wall-clock/resource ceilings and owned cleanup before use.
Unsupported extensions, links, traversal, duplicate names, checksum mismatch
or resource/cleanup uncertainty refuse the phase. Retain an immutable
inventory and compare source archive members to the exact reported Git tree
with an independently reviewed membership method. Do not equate equal version
strings or cgit blob observations with this equivalence.

Compare the authenticated archive against the **23 already retained source
files** and their exact pinned hashes, including the eight helpers. Reconcile
the known passthrough/options/program/command/meminfo behavior with source
archive membership. Then name only unresolved locale/debug/error descendants,
actual build configuration and library provenance in a separately reviewed
finite manifest. Unknown edges stop the gate; no recursive fetch or duplicate
request for a known helper.

Installed `dpkg-deb` binary/package membership, actual loaded libraries, ABI,
real archive-format compatibility and Core Media authority remain separate
proofs even if this static source phase passes.

The earliest reviewable next decision is therefore **Stage D plus the pinned
trusted-key/verifier policy**, not a two-file live acquisition. The literal
archive URL, signed source/archive-to-Git relationship, installed build/binary
correspondence and locale/debug/error/runtime closure are explicit blockers.
Both spent source corpora and all four native Reader refusals remain terminal.

`docs/reviews/media-reader-helper-review.md` and
`docs/reviews/media-reader-helper-gates.json` for the separate historical
