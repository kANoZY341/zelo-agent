## Fixed data contract

The caller supplies a frozen trusted ExpectedBinding: archive SHA256/size,
source-proof SHA256, reader-policy SHA256, a 32-lowercase-hex run ID and fixed
fsys-tar action. The manifest must match that exact binding. These values are
caller-supplied identity expectations, NOT signatures or grants of authority.
An independently supplied OwnerOutcome records exit code, EOF, parser completion,
cleanup, cancellation, timeout, stdout/stderr saturation and observed stream size.
Those outcomes must come from the eventual qualified owner, never the child JSON.
Any failed/uncertain outcome refuses permanently even with exit zero.

Input is exact built-in bytes <=4MiB. Bound before JSON decode. Reject duplicate
JSON keys, non-finite numbers, malformed UTF8, extra/missing keys, noninteger
numbers and bool-as-int. JSON framing does not authenticate source data or provide
a hard memory guarantee; runtime use still needs a bounded qualified process.

A single inventory has exact schema/binding/expanded_bytes/members fields.
Require 1..8192 entries and an observed 512-byte-aligned stream <=64MiB.
Each entry has exactly ordinal/name/kind/mode/uid/gid/size/sha256/link_target.
Ordinal is its zero-based position. Kinds: regular, directory, symlink, hardlink.
Mode 0..4095 and UID/GID 0..2^32-1 are inert recorded metadata, not applied attrs.
Regular payload sizes <=64MiB; SHA256 is lowercase hex; the empty-file digest is
canonical. Non-files have zero payload and no digest. Only links have targets.

Names are 1..1024 UTF8 bytes and <=64 path components. Preserve exact spelling
and strip ONLY one leading './' and one trailing slash on a directory. Root '.'
or './' is a directory only, at ordinal zero. Reject absolute names, traversal,
empty/dot components, repeated slash, backslash, colon and nonprintable/control
characters. No Unicode/case normalization. Reject canonical duplicates and every
non-directory path used as an ancestor, regardless of entry ordering.
Link targets are bounded printable inert text (including legitimate '../' or
absolute POSIX targets), never resolved, traversed, created or treated as file
content. A later file selector must separately prove any link resolution.

Minimum possible tar extent is one 512-byte header per member, aligned regular
payloads and two zero blocks. Refuse contradictory sizes; this arithmetic does
NOT certify tar termination, PAX/GNU semantics or completeness. The later parser
must enforce extensions/sparse/type/termination rules before producing records.

A fixed eight-archive batch requires eight matching expectations/outcomes and
unique archive identities, a shared run/policy/source-proof binding, <=16384
members and <=128MiB observed expanded bytes. Aggregate raw JSON <=32MiB, bounded
before parsing any item. Precheck summed owner extents before individual parsing.
Return immutable normalized metadata with a raw SHA256 binding and authority=false.
Never return a runtime qualification or a support-release receipt.
