# v0.16 — Private WhatsApp outbound identity projection

This Core-only gate is the next step after the offline reply-intent and operator-decision ledger. It checks trusted raw provider IDs and the current App Secret identity against the opaque verified message, selected account, bound thread and exact approved saved reply. The result is ephemeral and explicitly has no transport authority. It does not send to Meta, store raw IDs or tokens, expose an API route, or claim provider account ownership or delivery.

A future sender must repeat current authority checks at dispatch time and separately qualify a one-use send claim, uncertain-outcome handling, provider response and status receipts, credentials, retry policy and live account operation. The published release remains v0.15.0.
