## Fixed first adapter language

The first adapter decodes only ELF header, program headers, section headers and
fixed dynamic records. Symbol/version/hash/relocation/note section bodies remain
uninterpreted and reported as such; their content identity is recorded. No ELF_Sym/
Versym or versions chain API is invoked, so neither x86 symbol-bit nor named-version
index interpretation is claimed. Those fields require a later supported-content gate.
This narrows the earlier full-platform implementation proposal to loader topology.

ELF64/little-endian/x86-64, EV_CURRENT, SystemV/Linux ABI version0, flags0, ET_EXEC/
ET_DYN only. Reject extended/sectionless counts:1..64programheaders,2..512sections,
exact64/56/64 header widths. PT_INTERP0or1, PT_DYNAMIC exactly1; no unknown program/
section tags. File-backed extents bounded; NOBITS has no body/hash/allocation. Compressed
sections rejected. sh_link indices bounded; interpreted dynamic/string links agree.

Dynamic records max1024 including NULL, exact16bytewidth, NULL required and all later
records zero. NEEDED alone may repeat; every other accepted tag is singleton. Dynamic
section/segment exact extent agreement; its linked STRTAB matches STRTAB/STRSZ via
unique full-range file-backed PT_LOAD mapping. Dependency/SONAME strings ASCII
[A-Za-z0-9_+.-],1..255bytes; search strings ASCII [A-Za-z0-9_+./:$-],0..4095bytes.
PT_INTERP absolute ASCII path with nonempty safe components, no dot/dotdot, firstNUL
within4096bytes INCLUDING terminator and only zero trailing bytes. No path resolution.
All strings searched only inside verified ranges and bounded4096bytes; charge bytes
examined before work,131072bytes perinput,32768emitted stringbytes. Output<=65536.

| Accepted dynamic category | Tags | Treatment |
| --- | --- | --- |

All other dynamic tags reject, including audit/filter/auxiliary/config, Android,
architecture-specific and unknown integer tags. Recognized uninterpreted records are
visible evidence, never silent platform completeness. Complete platform lock/build
still needs loader behavior, symbols/versions/dlopen and provenance qualification.
