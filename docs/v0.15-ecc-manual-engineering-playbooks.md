# ECC engineering playbooks — Zelo manual candidate library

The Managing Director selected Everything Claude Code (ECC) as the second
integration after Open Code Review. Four ECC skill references are already
retained as inert, exact-commit, MIT-licensed source evidence in the curated
community import.

This follow-up adds four **Zelo-authored, operator-only manual procedures**:
security review, agent evaluation, AI regression testing and architecture
decision records. Each contains a concrete ordered checklist, required proof
and refusal conditions. They are human-inspectable, not live agent instructions.

## Read-only API

GET /integration-candidates/community/skills/{skill_id}/playbook

Accepted IDs: ecc_security_review, ecc_agent_evaluation, ecc_ai_regression,
ecc_architecture_decisions. The endpoint requires existing operator auth.
It verifies pinned source identity, returns canonical procedures and a
SHA-256 playbook fingerprint, and refuses unknown skills. It does not accept
mutations or run upstream SKILL.md instructions.

## Authority and acceptance

All playbooks are manual candidates. None is an active Skill Registry entry,
qualified agent behavior, automated learning outcome or production prompt.
No Worker, Task, Space, Tool, Computer, network, publish, approval or merge
permission is granted.

Future activation requires fixed evaluations, independent observations,
identity and capability compatibility, and Managing Director approval using
Core's existing governed promotion and revocation process. Keep the UI PR #61
parked, the REA authority boundary unchanged, and Media proof attempts intact.

See the import program in v0.15-curated-community-import-program.md and
tracking issue https://github.com/kANoZY341/zelo-agent/issues/132 .
