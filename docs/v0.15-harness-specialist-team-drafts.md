# Harness Agent Factory proposals — YouTube and Trading research

Harness source and license evidence remains pinned and inert in the curated
community import. This follow-up extends the existing two proposal templates
with two operator-only draft teams, without registering or activating Agents.

## Organizational proposals

- youtube_content: YouTube VP → YouTube Content Director →
  YouTube Research Manager → YouTube Script Writer Specialist.
- trading_research: Trading VP → Trading Intelligence Director →
  Trading Risk Manager → Market Researcher Specialist.

Both fit underneath the existing Managing Director → Zelo CEO hierarchy.
They contain four immutable draft AgentSpec records with verified parent IDs,
unique identities, per-agent memory namespace and a SHA-256 fingerprint.

## Read-only preview routes

GET /integration-candidates/community/teams/youtube_content

GET /integration-candidates/community/teams/trading_research

The existing operator bearer authentication applies. Each response requires
Managing Director review, with no Worker or Tool grants, no Space permissions,
no Task creation, no subagent authority, no active Skill and no persistent
Computer. This does not connect to a real YouTube account, upload video,
access brokerage funds, place trades or make commitments.

## Activation gates

Actual instance creation, budgets, delegation, source verification, account
authentication, human approval and execution-time revocation must be
independently qualified before any live specialist is allowed. The imported
Harness code never becomes a second agent orchestrator.
