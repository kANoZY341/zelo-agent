# Zelo Core v0.15 — Media PNG contract qualification

First outcome: a qualification-only immutable byte/evidence contract for a PNG
thumbnail operation, followed by a separately qualified isolated Pillow adapter.
No image decoder runs in Core. No task/worker/capability/Agent/Mind route or runtime
configuration is added in the contract slice. No host path, URL, file fetch, video,
SVG, PDF, EPS, animation, OCR, generation, fonts, arbitrary filters or caller code.

Reuse evaluation (3 October 2026): Pillow provides PNG loading, RGBA conversion and
aspect-preserving thumbnail generation under MIT-CMU. Its security guidance calls
for format allowlists, pixel/file/deadline ceilings, metadata stripping, pinned
hash-verified packages and isolated processing because native parsers remain an
attack surface. No Pillow package is installed in Core. Exact package/native
provenance and licensed notices are later prerequisite gates; candidate version
12.3.0 is not an approved attachment. FFmpeg has a wider protocol/codec surface and
build-dependent LGPL/GPL obligations; defer video. Chromium is already qualified
for script-disabled text, but adding image processing/evaluation would change that
contract; preserve the existing Browser lane and evaluate Pillow separately.

Contract scope: immutable exact bytes, not paths or automatic Base64/coercion.
Accept a small noninterlaced 8-bit RGB/RGBA PNG subset with only IHDR, consecutive
IDAT and IEND. Input <=262144 bytes; width/height <=1024; pixels <=1048576; 1..32 consecutive IDAT
chunks (empty chunks permitted, aggregate IDAT data must be nonempty). One first
13-byte IHDR, positive dimensions, compression/filter zero, and one final empty
IEND are required. CRC covers chunk type plus data; length checks precede slices. Check signature, chunk bounds/order/count, CRC, header fields and exact
end of PNG framing without decompressing or invoking any codec. Reject metadata,
profiles, animation, palette, unknown chunks and trailing bytes. This is bounded
framing validation, not proof of valid compressed pixel data or source provenance.
Malformed compressed data may pass the envelope and must fail in the isolated
decoder before a successful runtime result.

Request: fixed thumbnail-fit operation, no upscale, requested fixed LANCZOS and RGBA8 output;
strict integer bounding box 1..256 per side. Bind immutable source SHA-256, exact
box and fixed semantic policy digest to request digest. No decoder/executable/env/
path/mount/plugin/metadata/filter/runtime selection in untrusted input.

Candidate output: <=262144 bytes and 1..32 IDAT chunks under the same framing, 8-bit RGBA, <=256 per side, within the
requested box and original dimensions; output/source hashes are computed from retained exact bytes. Versioned canonical
JSON binds source hash, box and fixed policy hash to the request identity. Candidate
validation receives the validated request and compares supplied source/request/
policy hashes against it, never only against other caller-supplied values.
Do not claim a framed PNG is decoded-valid, that dimensions prove aspect accuracy,
that CRC authenticates anything, or that returning candidate bytes confirms native
cleanup. Use an immutable candidate-specific type with non-overridable instruction trust
none; no success/cleanup/provenance flags. Reject unknown constructor fields,
mutable bytes and coercible integer inputs. Dimensions derive from framed bytes.
All returned data has instruction trust none. Candidate evidence cannot
serve as runtime acceptance or selection authority; later runtime release requires
actual decoder success, exact native identity and confirmed ownership cleanup.

Planned adapter gate: pinned independently reviewed Pillow/native bundle; fixed
isolated entry, no inherited environment/site plugins, workspace/credentials/
network/write authority; all source verification/startup/decoding/encoding shares
one absolute deadline; host and native output bounded; RLIMIT/cgroup/seccomp and
actual namespace/descendant ownership probes. Retain existing OwnedProcess and
durable admission invariants; unknown cleanup remains fenced and produces no
partial successful evidence. Do not import broad unqualified Python runtime
semantics or declare RLIMIT_NPROC a complete fork boundary. No installation or
backend implementation belongs in this first contract slice.

Delivery: document scope and checkpoint previous Shell operator gates; regression
fixtures built from small standard-library chunks without optional decoders; test
CRC/order/truncation/dimension/byte/count/type/mutable-input rejection, digest
binding, candidate output constraints and explicit malformed-compressed acceptance.
Independent Astra Medium static review, focused offline checks and exact-head full
CI before merge. Subsequent native qualification and Core binding remain separate.
UI stays parked, production Browser/Shell disabled, published v0.14.0 unchanged;
v0.16 channels -> v0.17 organizations -> v0.18 autonomy remains ordered.
