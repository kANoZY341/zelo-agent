# v0.15 Media private normalized file preparation

After wheel inventory PR #74, implement the smallest operator-only copy gate.
Reuse the closed immutable bytes inspector, standard-library ZIP and unchanged
ArtifactManifest scanner. No package import/install/execution, native image, Core
factory/capability/task/route, model request or live configuration change.

The public function accepts strict wheel bytes only; it inspects before filesystem
writes. Its destination is a new owned private attempt under this dedicated
repository runtime/media-file-preparation. No caller path, overwrite, environment
selection, ZIP extraction helper, plugin/install hook or Pillow installation.
Private fixture seams may accept synthetic inspected bytes and pytest private roots;
they are not application APIs. At most four retained attempts per diagnostic root;
refuse a fifth without deleting evidence. Operator-managed trusted ancestors, a
local Linux filesystem and no concurrent preparers/same-user mutator are assumed.

Create attempt/payload directories 0700, files 0600 exclusively using relative
NOFOLLOW/NONBLOCK/CLOEXEC descriptors. Check directory/regular type, current uid,
private permissions, file link count one, and stable descriptor/path identity.
Open components individually; hold at most depth + six directory/file descriptors.
Re-read the same inspected bytes using bounded ZIP streams; recheck running size,
SHA, CRC/EOF and complete path closure. Buffers are at most 65,536 bytes; no whole
expanded file buffering. Handle short writes by looping and reject zero progress.
Fsync each file, normalize by descriptor, fsync again and close. Every descriptor
close is attempted, including after another close fails; all write/fsync/scan/close
errors prevent a receipt. Retain bounded partial attempt evidence; no success claim.

Data files normalize to 0400. Exactly the eight NATIVE_EXTENSIONS and eighteen
BUNDLED_LIBRARIES paths from the fixed inspector normalize to 0500, with fixed
roles native_00 through native_25 in sorted path order. These roles satisfy the
unchanged scanner's executable presence contract; they confer no execution
permission in Core. Directories, including the payload root, normalize to 0500
bottom-up, with descriptor fsync. ZIP modes are never copied. Notice/SBOM files
are retained in full. Scan policy: 512 files, depth 8, 16 MiB/file, 64 MiB total,
512 non-root entries; root plus explicit/implicit empty directories are accounted.

Bind the pathname root to the created directory's device/inode before and after
independent scanning. Compare all scanner file paths, sizes, hashes and normalized
modes, all directory paths/modes (including root), roles and policy exactly against
the closed inventory. Preserve the scanner's Browser schema; wrap its result in a
scanner-only frozen versioned Media receipt binding archive/inventory, normalization
policy, root identity and manifest digest. Keep any operator proof JSON outside the
payload. Attribution is explicitly unverified and instruction trust none.

Prepared files are normalized, not immutable: owner/admin can change read-only
modes and contents. The trusted-ancestor scanner and identity comparisons detect
changes but do not defeat concurrent same-user/admin mutation or freeze a tree.
Byte/count/descriptor bounds do not bound stalled filesystem calls. No runtime
absolute deadline or owned-process cleanup acceptance is implied.

Publisher cryptographic verification is a separate pinned mature-tool gate. This
copy receipt can exist with attribution unverified; the combined preparation gate
remains incomplete until exact authenticated subject/repository/workflow/commit,
trust roots, transparency evidence and confined verifier writes are qualified.
No custom cryptography or verifier installation in this slice.

Require adversarial offline partial-write/fsync/close/path/mode/identity/scan failure
fixtures, actual clean-head private preparation of the pinned wheel, independent
Astra Medium exact full review, full CI and installed-Codex supplements. Preserve
Browser/Shell semantics, production flags, v0.14.0, parked UI and later milestones.
