# Media GNU version graph metadata — design candidate

Continue after PR80 loader metadata, merged f6a8a584. This document is a design
candidate requiring Astra Medium review before implementation. No new guest/parser
execution is authorized here. The exhausted four-attempt loader qualification stays
retained and closed. A future version-graph qualifier is a distinct reviewed scope,
not a way to rerun that old qualification or reset its counters.

## Purpose and exclusions

Read bounded GNU version definitions, requirements and version-index frequencies
for the same seven pinned data buffers. Keep loader metadata identity as a bound
prerequisite. Do not decode Elf_Sym bodies or symbol names/values/other bits; those
remain uninterpreted. No symbol-provider resolution, ABI compatibility, relocation,
PLT rewriting, native loading, dependency discovery, complete platform, cgroup,
filter, Pillow, decoder or Core route. All such authority fields remain false.

The accepted loader evidence shows dynamic symbol table lengths equivalent to
104/2286/203/62/80/3156/40 entries, using recorded24byte widths. Version-definition
counts are0/0/0/0/5/41/7; requirement-parent counts3/3/2/1/1/1/0. These are topology
observations, not decoded symbol/version bodies or ABI guarantees.

## Reuse and wire representations

Reuse pinned pyelftools0.33 only inside authenticated guest, fixed structs through
struct_parse: Elf_Verneed16,Elf_Vernaux16,Elf_Verdef20,Elf_Verdaux8,Elf_Versym2.
No high-level sections, version iterators, symbol-count hash heuristics or external
loaders. Existing ELF loader adapter remains unchanged. New adapter may use its
validated record metadata and range/string primitives without weakening its rules.
Do not instantiate ELFHashTable/GNUHashTable. Hash fields are recorded unverified in
this slice; no new library import or homemade binary parser for hash validation.

Pinned Versym returns VER_NDX_LOCAL/GLOBAL strings for0/1, integers otherwise, plus
named reserved aliases VER_NDX_LORESERVE/ELIMINATE. Normalize only0/1 names; reject
other named aliases. For integer entries preserve bit0x8000 as hidden, index&0x7fff.
Only0/1 without hidden or indices2..0x7eff with either hidden state are supported.
Do not infer symbol binding/definition/provider from hidden or version index alone.

## Supported table combinations and links

Exactly one SHT_DYNSYM linked to the same bounded dynamic STRTAB, entsize24, size
multiple24 and count1..32768. This verifies table shape only, not symbol records.
Require DT_SYMTAB/DT_SYMENT24 and unique full-range LOAD mapping to that section.
Version tables are each0or1 and uncompressed: SHT_GNU_versym entsize2 links DYNSYM;
SHT_GNU_verdef/verneed entsize0 link dynamic STRTAB. Their file ranges must not
intersect each other or DYNSYM/STRtab. Allocated addresses must uniquely map back to
these exact file ranges. Verdef/Verneed sh_info agrees with the associated parent count; VERSYM sh_info
must be0 in this supported language.

If all three version sections absent, VERSYM/VERDEF/VERDEFNUM/VERNEED/VERNEEDNUM
must all be absent; report explicit unversioned topology. Otherwise require VERSYM
with exactly dynsym_count*2 bytes and DT_VERSYM mapping to it. Each definition or
requirement table requires both pointer/count tags, and vice versa; absent table
requires both tags absent. Counts1..128, no zero-present table. VERSYM-only permits
only LOCAL/GLOBAL indices. Unknown/missing companions refuse the whole input.

## Parent and auxiliary chains

All parent revisions exactly1. Parent records start at table offset0; decode exactly
the declared parent count. Nonfinal parent next must be nonzero,4byte aligned,
strictly forward by at least parent width and inside table. Final next exactly0.
Each parent owns a span ending at next parent or table end. Auxiliary displacement
must be4byte aligned and at least parent width. Aux count1..64 per parent, combined
<=1024 across both tables; parent total<=256 across both tables. Aux records remain
inside their parent span, move forward by at least their width, nonfinal nextnonzero,
final nextzero. Track visited offsets and occupied intervals; reject overlap/cycles.
Unoccupied gaps/trailing bytes inside version tables must be allzero, checked within
bounded table extents. Each table<=65536bytes, both<=131072. Charge bytes examined
before scanning. No input-sized allocation or dereference before range/count checks.

Verdef flags mask0x3 only (BASE/WEAK); vd_ndx1..0x7eff, no hidden bit. Index1 must
be BASE and only index1 may be BASE; exactly one base definition when table exists.
First aux name defines this record, later names are inheritance edges. Definition
names unique; no duplicate/self parent edges; every parent name must exist locally;
reject graph cycles with bounded iterative traversal. Base name equals SONAME;
therefore a definition table in this first language requires SONAME. vd_hash recorded
as uint32 and explicitly hash_verified=false. No loader interpretation of WEAK.

Verneed flags on auxiliary records allow only WEAK0x2; vna_other2..0x7eff without
hidden. Each provider filename must equal a recorded NEEDED name; no path resolution.
Requirement indices unique and must not collide with definition indices. Provider/
version pairs unique. vna_hash recorded uint32/hash_verified=false. Need/definition
names ASCII[A-Za-z0-9_+.-],1..255, strictly NUL-terminated inside verified STRTAB.
Every Versym index>1 must exist in the unique local need/definition index map.
Output frequencies by raw index/hidden state, not guessed per-symbol associations.

## Revision 2: closed contract addressing design review

This section refines the candidate above; where more specific it controls. All new
rules remain a supported subset. The pinned GNU header defines BASE1/WEAK2,
LOCAL0/GLOBAL1 and reserved raw aliases0xff00/0xff01. Its Verdaux name field covers
version/dependency names; dl-version.c uses the first auxiliary name for a definition.
Additional names are recorded in declaration order as metadata dependency edges.
Requiring local closure, acyclicity, BASE/SONAME equality, unique provider parents,
zero gaps and masked indices<=0x7eff are deliberately narrower policy choices, not
claims that GNU rejects other representations. No GNU maximum or complete coverage
is asserted. Pinned source identities/crosscheck above satisfy provenance for these
observations; no library code has executed in the new scope.

### Exact output objects

Every object has exactly the listed keys, never extra keys. Integers exclude bool;
strings are ASCII. SHA256 is64lowercasehex. uint16/uint32/uint64 mean strictint
0..2**width-1; counts use the tighter bounds below. Arrays retain stated order.

Top-level keys:
- schema:literal zelo-media-elf-version-graph-v1.
- source_bytes:int64..16777216; source_sha256:SHA256 of supplied buffer.
- loader_report:complete zelo-media-elf-loader-topology-v1 object produced by the
  unchanged adapter on that same buffer. Host applies its existing closed result
  acceptance to canonical(loader_report)+newline and the exact original bytes.
- loader_report_sha256:SHA256 of canonical(loader_report) WITHOUT newline, matching
  the unchanged adapter's returned byte convention. Host independently recalculates.
- versioned:strictbool, true iff VERSYM exists.
- tables:exact keys dynsym,dynstr,versym,verdef,verneed. First two always objects;
  others either object or null (never empty fake objects). A table object has exactly
  section_index,offset,bytes,address,entry_bytes,link,info,content_sha256. Numeric
  fields strictuint64 except section_index/link/info bounded to loader section count
  or documented counts. Identity equals the corresponding loader section fields and
  content hash, including linked table indices; roles have required types/widths.
- counts:exact keys dynsym,versym,definitions_declared,definitions_decoded,
  needs_declared,needs_decoded,definition_aux_declared,definition_aux_decoded,
  need_aux_declared,need_aux_decoded,inheritance_edges. dynsym1..32768;versym0or
  dynsym. Parent counts0..128/table; aux totals0..1024 combined; edges0..1024.
- definitions:list sorted by index,0..128. Each exact object: index(uint16,
  1..0x7eff),flags(uint16 masked3),hash(uint32),name(grammar1..255),
  dependency_names(list of grammar strings in wire auxiliary order excluding first),
  aux_declared(int1..64),aux_decoded(equal). aux_decoded=1+len(dependency_names).
- needs:list in wire parent order,0..128. Each exact object:provider(grammar),
  aux_declared(int1..64),aux_decoded(equal),versions(list in wire auxiliary order).
  Each version object exactly:index(2..0x7eff),flags(uint16 masked2),hash(uint32),
  name(grammar1..255). aux_decoded=len(versions). Provider parents unique.
- frequencies:list sorted strictly by raw,0..2050. Each exact object:
  raw(uint16),index(raw&0x7fff),hidden(strictbool equal bool(raw&0x8000)),
  count(strictint1..32768). Supported index restrictions above apply. Unique raw
  buckets; sum counts=dynsym iff versioned, otherwise list empty and versym=0.
  No fabricated LOCAL/GLOBAL counts for an unversioned input.
- supported_version_graph_structure_verified:literal true, referring only to this
  restricted structural language; symbol_content_verified,version_hash_verified,
  abi_qualified,platform_complete,runtime_authority:literal false;
  instruction_trust:literal none.

Absent definition/need table requires corresponding list and declared/decoded/aux
counts allzero. Present table parent counts match sh_info and dynamic count, lists
and decoded counts; totals match nested cardinalities and declarations. Inheritance
edge count=sum definition dependency_names lengths. Host validates exact keys/types,
all counts/links/identities/grammar/order/unique maps/claims and graph/index relations,
then canonical bytes+newline identity and total size; it does not import pyelftools
or reparse ELF. Reviewed guest source remains the parser correctness assumption;
independent host validation is binding/schema consistency, not a second ELF oracle.
Names reference declared version metadata, not resolved symbol providers.

### Explicit work accounting and chain refinements

Verdef/Verneed bodies <=65536each and131072combined; VERSYM separately<=65536.
Fixed-record decode count<=34048 and fixed-record bytes<=98304 per input, charged
before EACH decode, including any repeated read. Decode only after complete width
is inside its table AND owning parent span. Version strings retain4MiB examined,
4096/search including terminator; search allowance charged before .find. Emitted name
budget32768 excludes terminator, includes EACH appearance of names/provider strings
in output (including repeated dependency names); fixed JSON keys are accounted by
serialization. No caching bypasses either budget.

Parent next is relative to its current parent. Initial aux is relative to its owning
parent. Each auxiliary next is relative to that auxiliary and MUST be4byte aligned,
forward by at least its record width, and fully contained before decode. Occupied
intervals are only decoded record bytes, not parent ownership spans. At most1280
parent/aux intervals; insert at most1280, sort by offset, then adjacent comparisons
<=1280; all overlap/containment comparisons charged to4096 perinput. Table disjointness
checks<=32. Complement padding scans performed once per table, every byte charged
before scanning, total<=131072. Nonzero byte refuses. No repeated gap rescans.

Definition indices unique BEFORE map insertion; need indices likewise, and maps
strictly disjoint. Definition names unique, provider parents unique, provider/name
pairs unique, dependency names unique within each definition. No dictionary overwrite
may repair a collision. Iterative graph traversal<=4096 vertex/edge processing steps,
<=128 vertices/1024edges, charged before each step; detect multi-node cycles separately
from record-chain cycles. Frequency construction exactly one pass<=32768 increments;
map<=2050 buckets. Sort keys within these finite limits. No recursion proportional to
untrusted chains/graph depth. Each budget has a fixed refusal code.

Canonical JSON uses sorted keys, separators comma/colon, ASCII, no NaN. Build via
incremental encoder chunks into bounded private bytes; check accumulated bytes plus
next chunk plus final newline<=65536 before append. All string values individually
bounded (loader fields under existing rules, graph names<=255); object counts above
bound in-memory encoder input. On overflow discard result and refuse whole input;
never emit a partial success. No implication that32768namebytes guarantees fit.
The host enforces identical serialized byte ceiling. Loader adapter budgets separate.
