## Streaming contract and limits

parse_index accepts a trusted iterable of exact bytes chunks, each1..65536bytes.
Empty chunks refuse. Total128MiB is charged before processing each chunk.
At most100000stanzas,256unique fields/stanza and65536bytes/stanza.
Stanza count is charged before accumulating the first nonempty line.
Each nonempty line's LF and the first terminating empty separator LF count toward
the active stanza. Additional/leading empty separators count only globally.
EOF after a field LF finishes the stanza without an imaginary separator.
A65536-byte stanza can therefore finish at EOF but refuses one more separator LF.

Charge incoming partial segments against the stanza bound before slicing/appending,
even before LF arrives. Retain only current line, field names, needed simple
values and at most8selected records. Discard unknown continuation bodies.
No whole-input/chunk splitting. Success is independent of valid chunk partition
and logical field order. Iterator failures propagate without returning a result.
No intermediate records are yielded; malformed trailing input refuses the whole
index. Empty/separator-only input refuses. A valid nonempty index may select zero.

Strict UTF-8 is decoded on complete bounded lines. Decoded U+0000..001F except
tab, and U+007F..009F refuse; LF is framing. Never reject UTF-8 continuation bytes
by their byte values. CR, missing final LF, whitespace-only lines, comments and
orphan continuations refuse. These LF/whitespace rules are explicit policy
restrictions. Space-dot description continuations are ordinary discarded content.

## Fields and selected values

Field names:1..64ASCII characters in U+0021..0039 or U+003B..007E; first character
cannot be # or -. No whitespace before colon. Lowercase ASCII detects duplicate
fields in every stanza, including unselected entries. Package, Version,
Architecture, Filename, Size, SHA256 and Source are nonempty/unfolded if present.
Trim only ASCII space/tab at simple-value ends, never Unicode whitespace.

All stanzas require Package/Version/Architecture. Package and source names match
[a-z0-9][a-z0-9+.-]{1,127}; versions match [0-9][A-Za-z0-9.+:~-]{0,127};
architectures match [a-z0-9][a-z0-9-]{0,31}. Version validation is lexical metadata,
not complete Debian version validity/order. Exact selected versions are literal.

Selected rows require Filename, Size and SHA256. Filename is1..512ASCIIbytes,
at most8components, each1..128 matching [A-Za-z0-9_+@.-]+. Empty, dot and dotdot
components refuse without normalization/decoding. Require pool/main/ prefix and
.deb suffix. Colon, percent, backslash, query, fragment and absolute paths refuse.
Size matches [1-9][0-9]{0,7} and is1..33554432. SHA256 is64lowercase ASCII hex.
Unselected Size/Filename/SHA256 are generically bounded text, not numeric/path/
hash authority; no unselected field can drive allocation, I/O or returned records.

Selected Source is name or name + oneASCIIspace + parenthesized version, at most
259ASCIIbytes. Absent Source defaults diagnostic name/version to binary identity.
Bare Source defaults its version to binary Version. Explicit equivalent forms
normalize identically. These are declared metadata, not installed-source origin.

## Result validation and cross-suite merge

Per-index result exact keys: schema,suite,bytes,sha256,packages,metadata_only,
package_member_origin_verified,runtime_authority. Schema:
zelo-media-fixed-package-index-metadata-v1. Packages is an exact list length0..8.
Each selected record has exact keys package,version,architecture,filename,bytes,
sha256,source; source is an exact dict with name/version. Metadata-only is true;
provenance/runtime flags are false.

merge_fixed_indexes accepts only exact list/tuple length3, exactly one result
per fixed suite. Before merge it validates exact builtin structures and keys,
schema, boolean identities, exact integer types (not bool), all lexical bounds,
fixed membership and per-index duplicates. Caller-created dictionaries are still
untrusted metadata and never proof. Duplicate selected identities within one
index refuse even when identical.

Across distinct suites compare normalized package/version/architecture/filename/
bytes/SHA256/source-name/source-version. Equality is declared metadata equality,
not observed package bytes. Conflicts refuse; identical tuples coalesce with
suite memberships in noble/noble-updates/noble-security order. Descriptions,
dependencies and field order do not affect equality. All eight targets must be
present after all three inputs validate. Selection output schema:
zelo-media-fixed-package-selection-v1, fixed target/suite order, the same flags,
and three index content identities.
