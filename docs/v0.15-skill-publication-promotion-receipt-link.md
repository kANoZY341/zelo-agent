# v0.15 Skill publication promotion receipt link (local candidate)

This opt-in, unregistered service records an immutable **historical** link from
one accepted proposal and exclusive claim to a positive single-attempt GitHub
merge receipt. It is deliberately outside the existing Skill runtime resolver,
API, Runner and Tool registry. It cannot activate a learned Skill.

`SkillPublicationPromotionReceiptLinkService.record` requires the owner
principal, the exact frozen MergeRequest and the same successful, approved,
uncancelled Promotion Task that sourced the attempted merge. It rechecks the
claim, approved decision, dispatch fence, durable attempt and affirmative
response receipt. A missing receipt, uncertain outcome, or terminal failure
denies linkage. History-only reconciliation has no route into this link.

Before writing, it reads the provider's closed merged PR, immutable merge
commit with the recorded single parent, exact artifact blob in the merged
tree, and current main branch head. All provider calls are GET. Under SQLite
`BEGIN IMMEDIATE`, it recalculates the accepted proposal, live Agent,
predecessor, Task and entire receipt binding. Unique constraints and
append-only triggers prevent competing local receipt links; cross-table
triggers prevent a generic promotion link from superseding one. Exact retries
return the same stored link after full revalidation.

The provider observation and local SQLite commit are **not** a distributed
transaction. Another remote commit could move main after the GET. The link is
therefore inert evidence and cannot serve as a publication or activation
grant. Its receipt also does not establish an independent GitHub reviewer.
A future resolver must revalidate the raw database row's digest, accepted
proposal, claim, decision, fence, approved Task, positive receipt, exact
provider reviewer/head and current lineage at use time. The next gate needs
a provider-enforced exact-head review receipt and an independently qualified
Skill-specific resolver/activation path. Generic protected-path merge refusal
and the external one-attempt flag remain intact.
