# v0.15 — Monotonic promotion-head admission for learned proposals

## Purpose

PR #106 binds vN learned proposals to an exact, trusted and already-promoted v(N-1).
This follow-up prevents **new competing proposals for a version already promoted**.

The check runs only when submitting a previously unseen proposal. Core first
constructs/revalidates its existing AgentInstance, source Skill, evidence and
authority envelope. An identical proposal retry returns its immutable existing
record. For a genuinely new proposal, Core resolves the current verified
promoted history for that exact AgentInstance/Skill/procedure. If the new
revision's version is at or below the latest promoted version, Core refuses it
with the skill_learning_promoted_head_advanced error.

The resolver also rejects divergent promoted heads, invalid prior hashes,
version gaps, repository drift and history beyond 64 links. Those refusals
remain mandatory, even for historical records.

## What stays unchanged

- Existing frozen proposals and reviews remain revalidatable after promotion.
- A historical v1 or v2 idempotent retry does not create another proposal.
- A valid next vN after promoted v(N-1) can still be proposed.
- A different AgentInstance cannot borrow the promotion history.
- No change to Ahmad review, candidate materialization, Promotion, CI or Merge.
- No skill is loaded into the active Skill Registry; runtime_authority stays
  false and all capability/tool/Space permissions remain unaffected.

## Deliberate limitation

This submission-time guard cannot retroactively prevent two competing
proposals created **before either was promoted**. The resolver still detects
and rejects an ambiguous promoted lineage. A separately reviewed
promotion-time exclusivity guard would be required to prevent that scenario
at publication time; do not claim global version uniqueness from this slice.

## Verification

Adversarial tests cover promotion-before-new-proposal refusal for both v1 and
v2; replay of the exact historical proposal; successful v3 admission after
promoted v2; and the historical two-head ambiguity fixture (both candidates
submitted before either was promoted).
