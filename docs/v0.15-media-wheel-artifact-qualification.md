## Actual candidate shape and explicit archive-mode refinement

The fixed public wheel downloaded into a new private diagnostic file matched the
independently observed SHA exactly: 6,940,830 archive bytes, 145 entries (140 files
and five directories), 19,667,368 declared uncompressed bytes. No code was imported,
installed or extracted. It uses stored/deflated members, Unix creator, no comment,
flags or member extras. Roots are PIL, pillow.libs and pillow-12.3.0.dist-info.
METADATA 2.4 identifies pillow 12.3.0/MIT-CMU, License-File LICENSE; WHEEL 1.0 has
Root-Is-Purelib false and exactly cp312-cp312-manylinux_2_27_x86_64 plus
cp312-cp312-manylinux_2_28_x86_64. RECORD has 140 rows. Required package files include
PIL/__init__.py, _version.py, Image.py, ImageFile.py, PngImagePlugin.py and the eight
observed cp312 x86_64 native extensions. Preserve all eighteen pillow.libs native
libraries and all file hashes in the inventory. Metadata additionally requires
WHEEL/METADATA/RECORD, top_level.txt, zip-safe, licenses/LICENSE (70,307 bytes), and
sboms/auditwheel.cdx.json plus sboms/pillow-12.3.0.cdx.json. License text includes
multiple bundled-library notices; inventory is not complete licensing audit.

The archive declares regular 0644/0755 modes and 0755 directory modes, but RECORD
has declared regular 0664 and the Pillow SBOM uses type-unspecified 0600. These are
ZIP metadata, not installed filesystem permissions. The prior blanket proposal to
reject group-writable archive mode would reject the known RECORD without protecting
a filesystem in this read-only inventory scope. Refine explicitly: permit 0664 only
for the fixed RECORD path and type-unspecified 0600 only for the fixed Pillow SBOM;
reject other special/privileged/unsupported modes and require directory/type agreement.
Record declared permission values without granting/copying them. A later extraction
scope MUST create normalized private read-only files/directories and rescan them;
no raw archive permissions may become runtime authorization. No extraction exists
here. Native boundary/attestation/decoder/ownership approval remains ungranted.
