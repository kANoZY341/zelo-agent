Only strict bytes accepted. Bound archive bytes (8 MiB) and compare exact trusted
wheel hash BEFORE ZipFile parsing, decompression or reading members. Use standard
library zipfile, not a replacement ZIP codec. Reject unsupported/encrypted entries,
duplicate/noncanonical/traversal/absolute/backslash/nonASCII paths, symlink/special
entries, unknown top-level roots, directory/file-prefix collisions and archive
comment. Bound entries <=512, depth <=8, name length <=512, per file <=16 MiB and
total uncompressed <=64 MiB before member reads. Read in bounded chunks, derive
actual sizes and SHA hashes and require zip CRC completion. No file extraction.

Require exact Pillow/dist-info roots, known Python/PngImagePlugin and native ABI
codec files, Wheel-Version/Root-Is-Purelib/Tags and Name/Version metadata without
duplicate identity fields. Validate RECORD CSV inventory, SHA256 URL-safe base64
hashes and strict sizes for every file (only RECORD itself exempt), reject missing/
extra/duplicate rows. Preserve all license and native-library notices in inventory;
require Pillow LICENSE and required native codec/package fields. This validates
artifact shape/change detection, not decoder correctness or execution authority.
Use existing ArtifactFile inventory value semantics where appropriate; do not alter
Browser scanner/runtime policy or create a generic plugin/install framework.

Return immutable candidate inventory including archive pin, package/ABI tags,
complete sorted file/path/size/mode/SHA list and licenses, with canonical versioned
digest. No approved/runtime-success/cleanup/provenance flag or host path authority.
Compare future expected inventory/digest only as trusted operator assertions; byte
scan never creates provenance or grants execution. No untrusted caller can choose
another wheel version/URL/hash/parser or loosen bounds.

Independent Astra Medium design review tightened the next artifact contract:
- Accept only ZIP_STORED/ZIP_DEFLATED; Unix regular file mode or directory entries
  with matching trailing slash/type, safe non-writable group/other mode bits.
  Reject encryption/unsupported flags, ZIP64 and extra fields for this small fixed
  candidate after actual archive compatibility inspection; never weaken silently.
  Check original filename for NUL/control characters before normalized filename.
- The <=512 count check occurs after ZipFile central directory parsing; before it,
  the protections are <=8 MiB strict bytes and the closed upstream hash. Running
  actual member/aggregate counts must match declared sizes at successful EOF/CRC.
  METADATA/WHEEL/RECORD buffers <=131072 each; canonical metadata/CSV parsing bounded.
- Inspect exact pinned candidate shape before implementation, without import or
  extraction, to enumerate required package/native/plugin/license members, allowed
  metadata versions and tag-set agreement. Presence does not prove ABI/codec support.
  Multiple distinct Tag fields are allowed; singleton identity fields are unique.
- Require exactly three RECORD CSV columns, canonical paths/hash encoding/decimal
  sizes matching actual file bytes, one self-row with empty hash/size. Directories
  have no RECORD rows; reject unsupported RECORD.jws/p7s members for this candidate.
- Scanner-derived immutable nested tuple inventory only; archive modes are declared
  ZIP metadata, not actual filesystem permissions. Bind fixed policy/schema/closed
  wheel/tags/sorted file inventory/license references to its canonical digest and
  non-overridable instruction trust none. License inventory is not complete audit.
