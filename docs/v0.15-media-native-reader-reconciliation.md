# Media native-reader attempt-1 reconciliation and second-attempt gate

## Purpose

Recover from the retained attempt-1 **lease-preflight refusal** without resetting
any proof or weakening admission. This is reconciliation of a stale safety fence,
not qualification success and not a retry.

Attempt 1 remains consumed. The current admission marker is authoritative until
a separately reviewed reconciler proves the failed lease owns no Docker resource
and durably records that proof before clearing the marker.

## Immutable attempt-1 contract

Tracked inert fixture copies preserve the exact failed policy, refusal and marker:

- `qualification/fixtures/media-native-reader-attempt1-policy.json`;
- `qualification/fixtures/media-native-reader-attempt1-cases.json`;
- `qualification/fixtures/media-native-reader-attempt1-marker.json`.

`qualification/media_reader_reconcile.py` is pure validation only. It pins the
failed source head/tree, attempt name, lease identity, policy digest and exact
SHA256 values. It grants no marker-clear authority on import or validation.

The runtime failed attempt itself remains the primary operator evidence and is
never repaired from these fixtures.

## Explicit reconciliation operation

`scripts/reconcile_media_native_reader.py` may be run only after its own frozen
source review and matching CI. It must:

1. obtain an exclusive nonblocking flock on the existing admission lock inode;
2. require the exact pinned marker, policy and refusal proof;
3. require the retained attempt directory to contain only exact private
   `policy.json`, `cases.json` and an empty private `docker-config`;
4. use a fresh disposable Docker config, not the retained attempt config;
5. discover zero containers and zero images carrying the exact failed lease;
6. require a **global two-second Docker event silence window**, with no label
   filter, so unrelated daemon mutations also refuse reconciliation;
7. repeat exact failed-lease discovery and revalidate the failed proof;
8. re-read the marker byte-for-byte;
9. persist and fsync a new private pending reconciliation record in a separate
   namespace; never alter attempt-1 evidence;
10. only then truncate/fsync the admission marker while still holding the lock;
11. close/unlock before emitting an in-memory receipt binding pending evidence.

Any Docker event, Docker command failure, live lock, resource discovery, evidence
drift, marker drift, write/fsync/close ambiguity or prior reconciliation evidence
refuses. No automatic retry.

## Second-attempt protection

The native operator is hardened separately:

- existing attempt count is checked before per-attempt validation, so two retained
  attempts can never create a third regardless of directory enumeration order;
- the unique historical attempt-1 directory is accepted only with exact tracked
  policy/refusal hashes and an exact empty private retained Docker-config;
- a fresh pre-admission Docker readiness check validates Linux/amd64 and runc;
- that same fresh private config must observe a **global two-second Docker event
  silence window before admission**, so detected cross-project daemon activity
  stops before a lease or proof attempt exists;
- exact lease-labelled container and image preflight still runs after admission;
- attempt 2/2 is the final allowed native-reader attempt.

The quiet window reduces a demonstrated shared-daemon contention risk but does not
claim exclusive control of Docker after the window. Actual container ownership,
cgroup evidence and cleanup gates remain mandatory.

## Preserved authority boundary

Neither reconciliation nor readiness executes dpkg-deb, a dynamic loader,
compressor, package bytes, USTAR scanner or Pillow. No acquired .deb is eligible.
No Core route, enabled flag, user-data mutation, UI work, proof reset or ABI/runtime
authority follows.
