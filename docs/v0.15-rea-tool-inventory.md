# REA 6.0 — bounded operator-only tool inventory

The operator selected the pinned in-repository REA source (merged via PR #119).
REA's source-built MCP endpoint advertised 139 tool names. Those names are
metadata, **not** permission for Mind, the Agent Factory, tasks or workers to
invoke them. Future trusted Core registration and target authorization remain
separate milestones.

The operator-only read endpoint `GET /integration-candidates/rea/tools` now
shows precisely 139 alphabetically sorted names with a narrow status:

- `analyze_javascript_application`: `manual_fixed_fixture_only`. The
  source-built no-network MCP proof runs only the pinned benign two-file
  qualification fixture when invoked directly by an operator. This does **not**
  approve arbitrary JavaScript/ASAR artifacts or any Zelo Worker.
- The other 138 tools: `unqualified`. The existence of upstream source,
  a matching name or tool effects does not imply execution readiness.

The endpoint is authenticated through the existing operator dependency.
Its response explicitly reports `execution_enabled=false`,
`worker_registered=false`, `grants=[]`. It has no mutation, tool-call,
auto-install or Docker start route. A missing, swapped, oversized or changed
catalog refuses with HTTP 503 and a bounded generic error.

Catalog origin is fixed to REA `rea-agents-6.0.0` commit
`6fee42689ae6e95a0182e0d4d0f55644e73e72be`. Zelo validates the
exact source-built, no-network inventory schema and SHA-256
`82fb67571758c177d1eecac72efac152772cccc753442a77ef9418edc69be6a0`
before returning any name. Upstream documentation and the tool-effects map
remain untrusted supporting evidence; Zelo's Core-controlled grant system
continues to own all execution authority.

To make the first real REA analysis available, a later reviewed increment must
add immutable operator-selected artifact admission, independently qualified
source-built runtime, a separate read-only WorkerAuthority/ToolPolicy binding,
approval and claim-time revocation, tight resource/cleanup receipts and
untrusted Evidence handling. None of these grants is created by this inventory.
